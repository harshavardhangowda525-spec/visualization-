# Asset provenance

`apps/web/public/images/studio-hero.webp` and `podcast.webp` are generated concept photographs created for this implementation with the built-in image generation tool. They do not document the client's actual premises. Replace them with client-approved assets before launch. No stock-photo licensing claim is made.

Hero generation brief: cinematic warm beige cyclorama studio, softbox and lighting stands, director chair, cinema camera, dark polished concrete, warm side lighting, left negative space, no people/logos/text.
Podcast generation brief: premium walnut sound-treated recording room, two microphones on boom arms, wooden table, cream chairs, warm amber light, no people/logos/text.

The original four-panel design concept informed the serif/sans typography, cream/charcoal palette, muted gold controls, large rectangular imagery and calm dashboard treatment. The implementation uses original code, not a screenshot as the UI. Concept-only fictional metrics/people in the image were not imported into the database. System fonts are used to avoid third-party font-network dependencies.
